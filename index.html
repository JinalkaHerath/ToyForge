Print Room / Filament Tracker
Finished prints from Print Wall — waiting for confirmation

Every print that ends on the print farm (finished, or stopped part-way) appears here automatically. The filament it used is read from the sliced file by Print Wall and taken from the Components stock straight away, so the stock always matches what the farm has printed. Check the part, colour and count, then press Confirm to add the parts to the printing records (changing the grams or colour corrects the stock). Dismiss removes a print without counting its parts. Prints marked Check this print are only taken from stock once confirmed. The part and count chosen for a file are remembered for the next time that file is printed.
